# תוכנית שינוי תגית הכשרות בהירו

## מטרה
להחליף את המשפט "בלי לבדוק תווית" בתגית ה-Hero ל"איכות ללא פשרות", כפי שהתבקש.

## שינוי מתוכנן
בקובץ `src/routes/index.tsx`, בשורה שבתוך `HeroCopy`, יוחלף:
- **מ-:** `כל המשקאות אצלנו כשרים — בלי לבדוק תווית`
- **ל-:** `כל המשקאות אצלנו כשרים — איכות ללא פשרות`

## אימות
לאחר השינוי יבוצעו:
1. בדיקת TypeScript (`bunx tsgo --noEmit -p tsconfig.json`).
2. צפייה ב-preview ובדיקה שורת התגית עודכנה בצורה תקינה.
