# מייל הזמנה חדשה אחרי תשלום

## מה יקרה
1. לקוח משלם בטרנזילה.
2. טרנזילה מודיעה לאתר שהתשלום עבר, וההזמנה מסומנת "שולמה".
3. באותו רגע נשלח אליך מייל "הזמנה חדשה #..." עם:
   - שם הלקוח, טלפון, מייל וכתובת למשלוח
   - רשימת הבקבוקים, כמויות ומחירים
   - מסלול המשלוח, סכום כולל, מספר אישור מטרנזילה
4. הלקוח מקבל מייל אישור משלו ("קיבלנו את ההזמנה").
5. בנוסף: לשונית "הזמנות" במסך הניהול, עם כל ההזמנות והסטטוס שלהן — גיבוי למקרה שמייל לא הגיע.

רק הזמנה ששולמה בפועל (והסכום תואם) שולחת מייל. לא יישלחו כפולים.

## מה צריך ממך
- **דומיין משלך** לשליחת המיילים (למשל kymrun.co.il). זה התנאי לשליחת מיילים — אין כתובת שליחה חינמית. ההגדרה נעשית בחלון ההגדרה.
- **כתובת המייל שלך** שאליה יגיעו ההזמנות.

## פרטים טכניים
- הגדרת דומיין שליחה ← יצירת תבניות מייל: `new-order-owner` (לבעלים, כתובת קבועה בצד השרת) ו-`order-confirmation` (ללקוח).
- השליחה מתוך `/api/public/tranzila/notify` אחרי סימון paid, עם idempotencyKey לפי מזהה ההזמנה.
- לשונית הזמנות באדמין דרך server function מוגנת ב-checkAdmin.
